# Getting Started

Welcome to the BDP Sandbox! This guide will help you get started quickly including how to access the environment, explore the data model, and run your first queries. Feel free to explore the other guides in the documentation summary for more advanced topics.

## 1. Setup Credentials

Before you can run any examples or queries, you need to set up your credentials. Follow the instructions in the [Setup Credentials](setup-credentials.md) guide to securely retrieve and store your API, Event Hub, and IoT Hub credentials.

## 2. Select Your Example to Run

There are several runnable examples available to try out different scenarios:

- If you need to explore what you can query, start with [GraphQL Quickstart](../examples/graphql-quickstart-python/).
- If you need to inspect endpoints and methods, start with [Explore REST Operations](../examples/explore-rest-operations-python/).
- If you need to make your first REST request in Python, start with [REST Quickstart (Python)](../examples/rest-quickstart-python/).
- If you need to make your first REST request in .NET, start with [REST Quickstart (.NET)](../examples/rest-quickstart-dotnet/).
- If you need to verify stream ingestion, start with [Event Hub Consumer](../examples/eventhub-consumer-python/).
- If you are preparing provider onboarding artifacts, start with [Point Group Configuration](../examples/point-group-config-python/).
- If you need to send sample provider telemetry, start with [Data Integration Framework (DIF) Telemetry Ingress](../examples/dif-telemetry-python/).

## 3. Learn about the different workflows

Based on your workflow, continue with either [Consuming Data](consuming-data.md) or [Providing Data](providing-data.md).
